# segctl.sh — Живое управление дисплеем и подсветкой Яндекс Станции Миди

**`segctl.sh`** — автономный скрипт для **Яндекс Станции Миди** (платформа `cucumber`), который поднимает прямо в оперативной памяти колонки легковесный веб-сервер с визуальным редактором сегментного дисплея, RGB-кольца и RGB-логотипа, а также встроенным проигрывателем анимаций `.binscled` / `.binscled.zst`.

Скрипт работает полностью в `tmpfs` (`/tmp/segctl`), не модифицирует системные разделы, не меняет конфигурационные файлы Алисы и не прописывается в автозагрузку.

## Пример работы



Полный цикл запуска и проверки кастомной индикации занимает меньше минуты:

1. **Загрузите скрипт во временную память колонки** с компьютера через `adb`:
   ```sh
   adb push segctl.sh /tmp/segctl.sh
   ```
2. **Запустите сервер** в шелле колонки (`adb shell` от имени `root`):
   ```sh
   sh /tmp/segctl.sh
   ```
   Скрипт проверит совместимость всех 45 светодиодов, RGB-кольца и утилит, после чего выведет адрес веб-интерфейса:
   ```text
   == проверка совместимости segctl ==
     [ OK ]  root есть
     [ OK ]  /tmp — tmpfs (всё в памяти, после перезагрузки чисто)
     [ OK ]  светодиоды: 45 из 45, имена совпадают
     [ OK ]  яркость пишется и читается обратно точно (сторож сработает)
     [ OK ]  максимальная яркость 255 (как ждёт редактор)
     [ OK ]  RGB-кольцо: 24 пикселей, запись работает — управление доступно
     [ OK ]  RGB-логотип: 6 пикселей — управление доступно
   Итог: полностью совместимо.

   segctl работает: открой http://192.168.1.50:8080
   Дисплей остаётся у Алисы, пока ты ничего не изменишь в редакторе.
   Остановить и всё убрать: sh /tmp/segctl.sh stop
   ```
3. **Откройте адрес в браузере** на телефоне или ПК (`http://<IP-колонки>:8080`):
   * Нажимайте или проводите пальцем по сегментам цифр, точкам и полоскам — они мгновенно загораются на колонке.
   * Выберите готовый пресет (например, *«Часы 08:24»*, *«Будильник, ringing»* или *«Волна по всем сегментам»*), напишите свой текст или запустите бегущую строку.
   * Откройте вкладки **«Кольцо (RGB)»** и **«Логотип (RGB)»**, чтобы раскрасить периметр колонки и логотип в любые цвета, либо скачайте готовую анимацию в формате `.binscled.zst`.
4. **Верните управление Алисе по завершении:**
   ```sh
   sh /tmp/segctl.sh stop
   ```
   *(Если вы меняли цвета RGB-кольца или логотипа, выполните `reboot`, чтобы перезапустить системный контроллер подсветки Алисы).*

## Зачем нужен `segctl.sh`

На Яндекс Станции Миди установлен 45-сегментный часовой экран, верхнее RGB-кольцо и 6-пиксельный RGB-логотип. Обычно создание и проверка кастомных анимаций (`.binscled.zst`) требует ручной упаковки файлов, копирования на устройство и запуска через системные утилиты. **`segctl.sh`** решает сразу несколько задач:

* **Мгновенное живое управление (Live-режим):** при открытии веб-интерфейса (`http://<IP-колонки>:8080`) любое нажатие на сегмент цифры, точку, центральную полоску или пиксель подсветки сразу отображается на физическом экране колонки с выбранной яркостью (`0–255`).
* **Полноценный редактор анимаций в браузере:** позволяет рисовать кадры, настраивать их длительность (`1–65535 мс`) и точку зацикливания, печатать текст и часы, генерировать бегущую строку, создавать плавные переходы (tweening по линейной или синусоидальной кривой), эффекты появления/затухания и склеивать дубликаты кадров.
* **Экспорт и импорт `.binscled` / `.binscled.zst`:** проект можно скачать в сжатом формате `.binscled.zst`, в несжатом `.binscled` (для `clock_led_util`) или скопировать готовую `base64`-команду для быстрой сборки файла через `adb shell`.
* **Защита от перерисовки часами Алисы:** фоновый процесс-сторож (`keeper.sh`) удерживает ваш кадр на экране, даже когда Алиса раз в минуту обновляет время, и автоматически останавливает конфликтующий цикл `/data/yse/clock.pid` (если установлен `YANDEX_Customizer`).
* **Диагностика совместимости и карты байтов:** встроенная команда `check` и инструмент сканирования байтов помогают убедиться, что прошивка, права `root` и раскладка `quasar.cfg` полностью поддерживаются.

## Как устроена работа скрипта

При запуске `segctl.sh` создаёт рабочую директорию `/tmp/segctl` в оперативной памяти и распаковывает в неё четыре компонента:

1. **Веб-сервер (`busybox inetd` + `http.sh`):** слушает выбранный TCP-порт (по умолчанию `8080`), отдаёт одностраничное веб-приложение (`www/index.html`) и обрабатывает REST API запросы (`/api/info`, `/api/state`, `/api/set`, `/api/play`, `/api/stop`, `/api/release`, `/api/ring`, `/api/ring/set`, `/api/logo/set`).
2. **Управление часовым дисплеем (`45` белых светодиодов):** напрямую записывает значения яркости (`0–255`) в `/sys/class/leds/cucumber:white:clock-*/brightness`:
   * **4 семисегментные цифры:** сегменты `a1..g1`, `a2..g2`, `a3..g3`, `a4..g4` и точки возле цифр `p1, q1, p2, q2, p4, q4, p5, q5`.
   * **Центральная секция:** горизонтальные полоски `h1, h2`, `m1, m2`, `l1, l2` и центральные точки двоеточия `p3, q3`.
   * **Символ градуса:** точка `deg` справа сверху.
3. **Сторож экрана (`keeper.sh`):** перед первой правкой скрипт сохраняет текущее состояние часов Алисы в `/tmp/segctl/snap`. Далее `keeper.sh` каждые `150 мс` сверяет фактическую яркость светодиодов с желаемым кадром (`/tmp/segctl/want/`). Если Алиса перерисовала часы (расхождение держится две проверки подряд), сторож обновляет снимок кадра Алисы в `snap` и мгновенно возвращает вашу картинку на дисплей.
4. **Проигрыватель анимаций (`player.sh`):** воспроизводит многокадровые анимации из `/tmp/segctl/anim.txt` непосредственно силами самой колонки (без зависимости от вкладки браузера), поддерживая однократное воспроизведение или бесконечный повтор с заданного кадра.
5. **Управление RGB-кольцом и логотипом:** автоматически находит в `/sys/class/leds/` каналы `cucumber:{red,green,blue}:ring0..N` и `cucumber:{red,green,blue}:logo0..N` и позволяет раскрашивать каждый светодиод в любой `HEX`-цвет.

## Важная особенность: обнуление RGB-кольца (`ring`) и перезагрузка колонки

> **Внимание:** Если во время работы вы изменяли цвета верхнего **RGB-кольца (`ring`)** или **RGB-логотипа (`logo`)**, после завершения работы со скриптом **колонку обязательно нужно перезагрузить**, даже несмотря на то, что `segctl.sh` автоматически гасит светодиоды (записывает `0` во все каналы яркости).

### Почему требуется перезагрузка?

1. При нажатии кнопки **«Отдать дисплей Алисе»** в веб-интерфейсе или при выполнении команды `sh /tmp/segctl.sh stop` скрипт проверяет наличие флагов `/tmp/segctl/ring_touched` и `/tmp/segctl/logo_touched`.
2. Если кольцо или логотип затрагивались, функция `rgb_blank` принудительно записывает нулевые значения (`0`) в файлы `brightness` для каждого цветового канала (`red`, `green`, `blue`) всех светодиодов кольца (`ring0..N`) и логотипа (`logo0..N`).
3. Однако для сегментного часового экрана скрипт хранит точный слепок состояния (`snap`) и возвращает его обратно, а вот **RGB-кольцом и логотипом в штатном режиме управляет системный демон Алисы (`quasar` / контроллер анимаций)** через собственные внутренние состояния и триггеры драйвера.
4. После прямой записи в `sysfs` (`/sys/class/leds/cucumber:*:ring*/brightness`) и последующего сброса в `0` состояние драйвера рассинхронизируется с системным сервисом Алисы: кольцо гаснет, но штатные световые анимации голосового помощника могут перестать корректно отображаться или обновляться.
5. **Полная перезагрузка колонки** чистит оперативную память (`/tmp`) и заново инициализирует контроллер подсветки, возвращая Алисе полноценное управление RGB-кольцом и логотипом.

## Все команды управления

Предварительно загрузите скрипт на колонку в каталог `/tmp` (например, через `adb push segctl.sh /tmp/segctl.sh`) и выполняйте команды от имени `root` (`adb shell`).

### Сводная таблица команд

| Команда | Назначение |
| :--- | :--- |
| `sh /tmp/segctl.sh` | Запустить сервер на порту по умолчанию (`8080`) с предварительной проверкой совместимости |
| `sh /tmp/segctl.sh start` | Явный запуск сервера на порту `8080` |
| `sh /tmp/segctl.sh start <порт>` | Запустить сервер на указанном TCP-порту (например, `8090`) |
| `sh /tmp/segctl.sh check` | Проверить совместимость колонки и свободный порт `8080` без запуска сервера |
| `sh /tmp/segctl.sh check <порт>` | Проверить совместимость колонки и доступность указанного порта |
| `sh /tmp/segctl.sh status` | Показать статус сервера, адрес редактора и кому сейчас принадлежит дисплей |
| `sh /tmp/segctl.sh stop` | Остановить сервер, вернуть часовой кадр Алисе, обнулить кольцо/логотип и удалить `/tmp/segctl` |
| `sh /tmp/segctl.sh help` | Вывести краткую встроенную справку (также работают ключи `-h` и `--help`) |

### 1. Проверка совместимости (`check`)

Перед первым запуском рекомендуется выполнить безопасную диагностику, которая ничего не запускает и не оставляет файлов:

```sh
sh /tmp/segctl.sh check
```

Или с проверкой конкретного порта (например, `8090`):

```sh
sh /tmp/segctl.sh check 8090
```

Команда последовательно проверяет **12 пунктов**:
1. Наличие прав суперпользователя (`id -u = 0`).
2. Размещение `/tmp` в оперативной памяти (`tmpfs`).
3. Наличие всех `45 из 45` светодиодов часового дисплея в `/sys/class/leds/cucumber:white:clock-*`.
4. Тестовую неразрушающую запись и чтение яркости на точке `deg` (проверка точности драйвера для работы сторожа `keeper.sh`).
5. Значение максимальной яркости `max_brightness` (ожидается `255`).
6. Наличие системных утилит: `inetd`, `usleep`, `setsid`, `dd`, `sh`, `kill`.
7. Поддержку флагов `iflag=count_bytes,fullblock` утилитой `dd` для чтения `POST`-запросов.
8. Корректность остановки фоновых процессов по группе (`setsid` + `kill -TERM -pid`).
9. Свободен ли выбранный TCP-порт (`8080` или переданный аргументом).
10. Наличие блокирующих правил `DROP` / `REJECT` в `iptables`.
11. Совпадение карты байтов `.binscled` (`digitParts` и `degreeLocation`) в `/system/vendor/quasar/quasar.cfg`.
12. Наличие и доступность записи для светодиодов RGB-кольца (`ring0..N`) и RGB-логотипа (`logo0..N`).

### 2. Запуск сервера (`start`)

Стандартный запуск на порту `8080`:

```sh
sh /tmp/segctl.sh
```

Либо с явным указанием команды `start` и пользовательского порта (если `8080` занят):

```sh
sh /tmp/segctl.sh start 8090
```

Если нужно пропустить автоматическую проверку совместимости при старте, передайте переменную окружения `SEGCTL_SKIP_CHECK=1`:

```sh
SEGCTL_SKIP_CHECK=1 sh /tmp/segctl.sh start 8080
```

После запуска откройте в браузере адрес, который выведет скрипт (например, `http://192.168.1.50:8080`). Пока вы не сделаете первую правку в редакторе, дисплей остаётся под управлением Алисы.

### 3. Проверка состояния (`status`)

Чтобы узнать, запущен ли `segctl`, на каком адресе и порту он работает, и перехвачен ли сейчас экран у Алисы:

```sh
sh /tmp/segctl.sh status
```

### 4. Остановка и очистка (`stop`)

Чтобы полностью остановить сервер, фоновый проигрыватель и сторожа, вернуть часовой экран Алисе, сбросить яркость RGB-кольца и логотипа в `0` и удалить все временные файлы из `/tmp/segctl`:

```sh
sh /tmp/segctl.sh stop
```

Если в процессе сессии вы управляли **RGB-кольцом** или **RGB-логотипом**, после выполнения `stop` перезагрузите колонку:

```sh
reboot
```

## Переменные окружения

Для нестандартных прошивок или отладки поведение скрипта можно настроить через переменные окружения:

| Переменная | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `SEGCTL_DIR` | `/tmp/segctl` | Рабочая директория в оперативной памяти для распаковки веб-сервера и хранения состояния |
| `SEGCTL_LEDS` | `/sys/class/leds/cucumber:white:clock-` | Префикс путей к `sysfs`-светодиодам сегментного часового дисплея |
| `SEGCTL_RING` | *(определяется автоматически)* | Ручное переопределение префикса путей к светодиодам RGB-кольца |
| `SEGCTL_TICK` | `150` | Интервал опроса сторожа `keeper.sh` в миллисекундах |
| `SEGCTL_SKIP_CHECK` | `0` | Установка в `1` отключает запуск `check_compat` перед стартом сервера |
